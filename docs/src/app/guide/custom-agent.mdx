# Custom Agent Loop

No framework? You only need three SDK calls per turn: `context()`, your LLM, `observe()`.

## The pattern

```python
from contexta_client import Contexta
from openai import OpenAI

client = Contexta.from_env()
llm = OpenAI()

def agent_turn(user_message: str, session_id: str) -> str:
    # 1. FETCH context before generation
    ctx = client.context(
        user_id=ACTOR_UUID,
        session_id=session_id,
        token_budget=1500,
    )

    # 2. CALL the LLM with that context as the system prompt
    reply = llm.chat.completions.create(
        model="gpt-4o-mini",
        messages=[
            {"role": "system", "content": ctx.to_system_prompt()},
            {"role": "user", "content": user_message},
        ],
    ).choices[0].message.content

    # 3. OBSERVE the turn
    client.observe(
        user_id=ACTOR_UUID,
        session_id=session_id,
        messages=[
            {"role": "user", "content": user_message},
            {"role": "assistant", "content": reply},
        ],
    )

    return reply
```

`context()` takes `user_id`, `session_id`, and optionally `organization_id`. **There is no `query` parameter** — if your integration passes one, the server drops it. For a query-shaped answer, use `retrieve()` instead.

## TypeScript

```ts
import { Contexta } from "@contexta/client";
import OpenAI from "openai";

const client = Contexta.fromEnv();
const openai = new OpenAI();

async function agentTurn(userMessage: string, sessionId: string): Promise<string> {
  const ctx = await client.context({
    userId: ACTOR_UUID,
    organizationId: ORGANIZATION_ID,
    sessionId,
    tokenBudget: 1500,
  });

  const reply =
    (await openai.chat.completions.create({
      model: "gpt-4o-mini",
      messages: [
        { role: "system", content: ctx.toSystemPrompt() },
        { role: "user", content: userMessage },
      ],
    })).choices[0]?.message?.content ?? "";

  await client.observe({
    userId: ACTOR_UUID,
    sessionId,
    messages: [
      { role: "user", content: userMessage },
      { role: "assistant", content: reply },
    ],
  });

  return reply;
}
```

In TypeScript, `userId`, `organizationId`, and `sessionId` are all **required** on `context()`.

## The `Context` object

`context()` returns something with four render methods:

```python
ctx.to_system_prompt()               # a system-prompt string
ctx.to_messages()                    # [{role, content}, ...]
ctx.to_markdown()                    # human-readable dump, for debugging
ctx.to_dict()                        # the raw response
```

```ts
ctx.toSystemPrompt();
ctx.toMessages();
ctx.toMarkdown();
ctx.toDict();
```

The default system prompt is sectioned by heading — user profile, rules, active projects, preferences, goals, recent events, relevant context — with empty sections omitted.

### Custom template (Python only)

`to_system_prompt()` takes an optional template string:

```python
ctx.to_system_prompt(template="""
# Memory Context for {user_id}
## Preferences
{preferences}
## Facts
{relevant_memories}
""")
```

The TypeScript `toSystemPrompt()` takes **no argument**.

## Use `flush()` and `close()`

Writes retry with backoff and queue to disk when the network is down, so an outage does not lose a turn:

```python
client.flush()   # drain the offline queue; returns entries replayed
client.close()   # release connections; safe to call twice
```

```ts
await client.flush();
client.close();
```

Or use the client as a context manager / `withContexta()` and get both automatically.

## A small agent class

```python
import os

from contexta_client import Contexta
from openai import OpenAI


class ContextaAgent:
    def __init__(self, api_key: str | None = None, user_id: str | None = None):
        self.client = Contexta(
            api_key=api_key or os.environ["CONTEXTA_API_KEY"],
            base_url=os.environ.get("CONTEXTA_API_URL", "http://localhost:8000/v1"),
            organization_id=os.environ.get("CONTEXTA_ORGANIZATION_ID"),
        )
        self.user_id = user_id or os.environ["CONTEXTA_ACTOR_ID"]
        self.llm = OpenAI()

    def run(self, message: str, session_id: str) -> str:
        ctx = self.client.context(
            user_id=self.user_id,
            session_id=session_id,
            token_budget=1500,
        )
        reply = self.llm.chat.completions.create(
            model="gpt-4o-mini",
            messages=[
                {"role": "system", "content": ctx.to_system_prompt()},
                {"role": "user", "content": message},
            ],
        ).choices[0].message.content

        self.client.observe(
            user_id=self.user_id,
            session_id=session_id,
            messages=[
                {"role": "user", "content": message},
                {"role": "assistant", "content": reply},
            ],
        )
        return reply
```

## If you want the agent to write rules too

`add_rule()` stores a decay-exempt behavioural directive, implemented on top of `observe()`:

```python
client.add_rule(
    user_id=ACTOR_UUID,
    rule="Never suggest deploying on a Friday",
    title="Deployment rule",
    tags=["process"],
)
```
