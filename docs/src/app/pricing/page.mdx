## Overage Rates

| Dimension | Rate |
|-----------|------|
| Observations | $0.002 each |
| Retrievals | $0.0001 each |
| Reranks | $0.003 each |
| Storage (per 1k memories/mo) | $0.50 |

Overage is billed at end of cycle. Hard caps can be enabled per API key to prevent surprises.

## Annual Discount

All plans are available with a 2-month discount when billed annually (10 months for the price of 12):

## Enterprise

Need dedicated single-tenant infrastructure, VPC peering, SOC 2 report sharing, BAA/DPA, or custom regions? [Contact us](mailto:licensing@contexta.dev) for a custom plan ($5k–$25k+/month).

## Self-Hosted Community Edition

Prefer to run everything yourself? The full stack is open source under the Apache 2.0 license for personal and non-commercial use. See the [GitHub repository](https://github.com/Aethlon/Contexta). Commercial use of self-hosted deployments requires a [commercial license](mailto:licensing@contexta.dev).

## What's Free

The following are never metered:

- API key management (create, rotate, revoke)
- Dashboard access
- Documentation, SDK downloads
- Audit log (within retention window)
- Memory deletion
- Data export (one quarterly full export per tier)
- Policy and schema management
