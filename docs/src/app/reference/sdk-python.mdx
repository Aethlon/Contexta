# Python SDK Reference

Full API surface for `contexta-client`, from `clients/python` in this repository.

## Installation

```bash
pip install -e clients/python
```

The package is not on PyPI yet.

## Classes

`Contexta` and `AsyncContexta` are the canonical names. The lowercase `contexta` / `Asynccontexta` still import and work but emit a `DeprecationWarning`.

### `Contexta`

```python
from contexta_client import Contexta

class Contexta:
    def __init__(
        self,
        api_key: str,
        base_url: str = "https://api.contexta.dev/v1",
        timeout: float = 30.0,
        max_retries: int = 3,
        telemetry: bool = True,
        enable_buffer: bool = True,
        buffer_path: str | None = None,
        organization_id: str | None = None,
        verify_tls: bool = True,
        ca_bundle: SSLConfig | None = None,
        ca_bundle_path: str | None = None,
    ): ...

    @classmethod
    def from_env(cls) -> Contexta: ...
```

`from_env()` reads `CONTEXTA_API_KEY` (required), `CONTEXTA_API_URL`, `CONTEXTA_TIMEOUT_MS`, `CONTEXTA_MAX_RETRIES`, `CONTEXTA_TELEMETRY`, `CONTEXTA_ORGANIZATION_ID`, `CONTEXTA_VERIFY_TLS`, and `CONTEXTA_CA_BUNDLE`. It raises `ValueError` if `CONTEXTA_API_KEY` is unset.

For a self-hosted install set `CONTEXTA_API_URL=http://localhost:8000/v1`. The `https://api.contexta.dev` default does not resolve to anything — there is no hosted API.

`AsyncContexta` takes the same constructor and method signatures; every method is a coroutine.

## Methods

### Ingestion

```python
def observe(
    self,
    *,
    user_id: str,
    session_id: str | None = None,
    messages: list[dict[str, Any]],
    metadata: dict[str, Any] | None = None,
    policy: str | None = None,
    idempotency_key: str | None = None,
    occurred_at: str | None = None,
    observed_at: str | None = None,
    source_id: str | None = None,
    message_id: str | None = None,
    timezone: str | None = None,
) -> ObserveResponse: ...
```

Returns `{"job_id": str, "observation_id": str | None, "status": "accepted"}`.

`user_id` goes out as the `X-contexta-User-Id` header, not in the body. It must equal the actor bound to your key, or the server returns `403`.

```python
def observe_batch(self, observations: list[dict[str, Any]]) -> BatchObserveResponse: ...
```

Up to 100 per call. Returns `{"jobs": [...], "errors": [...], "status": "accepted"}`.

### Recall

```python
def retrieve(
    self,
    *,
    user_id: str,
    query_text: str,
    session_id: str | None = None,
    memory_types: list[str] | None = None,
    tags: list[str] | None = None,
    limit: int = 20,
    graph_depth: int = 1,
    include_archived: bool = False,
    include_cold: bool = False,
    rerank: bool = False,
) -> list[ScoredMemory]: ...
```

> **`rerank` is accepted and transmitted but has no effect.** `POST /v1/retrieve` builds `ScopedRetrievalQuery`, which has no `rerank` field, so the extra key is dropped during validation. The HTTP retrieval path does not run a cross-encoder at all. The parameter is left in the signature for source compatibility; setting it to `True` will not change your results.

`user_id` and `organization_id` are optional in the request body — with a verified API key the server uses the key's own values and cross-checks anything you supply. Send them anyway if you want the mismatch to be caught early.

```python
def context(
    self,
    *,
    user_id: str,
    session_id: str,
    organization_id: str | None = None,
    token_budget: int | None = 2000,
    include_user_model: bool = True,
    num_recent_messages: int = 10,
    num_relevant_memories: int = 20,
    graph_depth: int = 2,
) -> Context: ...
```

`user_id`, `session_id`, and `organization_id` are **all required** here — `GET /v1/memories/context` has no defaults for them, and `organization_id` defaults to `self.organization_id` (i.e. `CONTEXTA_ORGANIZATION_ID`) when not passed, raising `ValueError` if neither is set. There is no `query` parameter; the endpoint does not take one.

Also available: `retrieve_batch(queries)`, `investigate(query, *, user_id, organization_id=None, max_hops=2, limit=15)`, `search(query, *, user_id=None, limit=20, threshold=0.65, memory_type=None)`, `hybrid(query, *, user_id=None, limit=20, max_hops=2, vector_weight=0.40, graph_weight=0.25, include_cold=False)`, and `traverse(source, *, hops=2, relationship_types=None, direction="both")`.

## Data types

```python
class Context(ContextModel):
    user_profile: UserProfile | None
    rules: list
    active_projects: list[Project]
    preferences: list[Preference]
    goals: list[Goal]
    recent_events: list[Event]
    relevant_memories: list[ScoredMemory]
    token_usage: TokenUsage
    cache_hit: bool
    request_id: str

    def to_system_prompt(self, template: str | None = None) -> str: ...
    def to_messages(self) -> list[dict[str, str]]: ...
    def to_markdown(self) -> str: ...
    def to_dict(self) -> dict[str, Any]: ...
```

`to_system_prompt()` accepts an optional template string.

```python
class ScoredMemory(ContextModel):
    memory: Memory          # the record is nested under `memory`
    score: float
    semantic_score: float
    graph_score: float
    importance_score: float
    recency_score: float
    keyword_score: float

class Memory(ContextModel):
    id: str
    user_id: str
    organization_id: str
    memory_type: str
    title: str
    content: str
    structured_data: dict
    tags: list[str]
    is_pinned: bool
    is_archived: bool
    memory_state: str
    created_at: str

class Explanation(ContextModel):
    memory_id: str
    source: dict
    classification: dict
    scoring: dict
    supersession_history: list[dict]
```

Note the shape change: retrieval results nest the record under `memory` and expose the score breakdown as **flat sibling fields**, not a nested `score_breakdown` object. `GET /v1/memories/hybrid` still uses the older flat `memory_id` + nested `score_breakdown` shape.

## Exceptions

```python
contextaError(Exception)             # base
├── AuthenticationError              # 401
├── AuthorizationError               # 403
├── ValidationError                  # 422
├── QuotaExceeded                    # 429 — never raised in v1.5, no quotas exist
├── RateLimited                      # 429, carries .retry_after
├── ServerError                      # 5xx
├── NotFoundError                    # 404
└── ConflictError                    # 409
```

## Retries, buffering, TLS

Every write carries an `Idempotency-Key`. `429`, `5xx`, and network failures retry with backoff of `retry_after or 2 ** attempt`, honouring the `Retry-After` header. When the network is down, writes queue to `~/.contexta/buffer.jsonl`.

```python
m.flush()   # drain the queue; returns entries replayed
m.close()   # release connections; safe to call twice
```

Use the client as a context manager to get both automatically.

Certificate verification is on by default. To trust the optional self-signed gateway:

```python
m = Contexta(api_key="…", ca_bundle_path="./certs/cert.pem")
```

Disabling verification is an explicit opt-in and never implicit:

```python
m = Contexta(api_key="…", verify_tls=False)
```

Passing both `ca_bundle_path` and `verify_tls=False` raises `ValueError` rather than silently weakening verification.
