# TypeScript SDK Reference

Full API surface for `@contexta/client`, from `clients/typescript` in this repository.

## Installation

```bash
npm install ./clients/typescript
```

The package is not on npm yet.

## Classes

`Contexta` and `AsyncContexta` are the canonical names. The lowercase `contexta` / `Asynccontexta` still work but log a single `console.warn`.

```ts
import { Contexta } from "@contexta/client";

class Contexta {
  static fromEnv(): Contexta;

  constructor(opts: {
    apiKey: string;
    baseUrl?: string;         // default https://api.contexta.dev
    timeout?: number;         // ms, default 30000
    maxRetries?: number;      // default 3
    telemetry?: boolean;      // default true
    organizationId?: string;
    tls?: TlsOptions;
    dispatcher?: unknown;     // pre-built undici.Agent (Node)
    fetch?: FetchLike;        // custom TLS-configured fetch
  });
}
```

`fromEnv()` reads `CONTEXTA_API_KEY` (required — throws `contextaError` with code `config_error` if absent), `CONTEXTA_API_URL`, `CONTEXTA_TIMEOUT`, `CONTEXTA_MAX_RETRIES`, `CONTEXTA_TELEMETRY`, `CONTEXTA_ORGANIZATION_ID`, `CONTEXTA_CA_BUNDLE`, and `CONTEXTA_VERIFY_TLS`.

For a self-hosted install set `CONTEXTA_API_URL=http://localhost:8000/v1`. The `https://api.contexta.dev` default does not resolve — there is no hosted API.

`AsyncContexta` takes the same config and the same method names, all returning promises.

## Methods

### Ingestion

```ts
observe(input: ObserveInput): Promise<ObserveResponse>;
observeBatch(inputs: ObserveInput[]): Promise<BatchObserveResponse>;
```

`ObserveResponse` is `{ jobId, observationId, status }` — there is no `estimatedProcessingSeconds`.

### Recall

```ts
retrieve(input: RetrieveInput): Promise<RetrieveResponse>;
retrieveBatch(queries: RetrieveInput[]): Promise<BatchRetrievalEntry[]>;
search(input: SearchInput): Promise<VectorSearchResponse>;
hybrid(input: HybridSearchInput): Promise<HybridSearchResponse>;
traverse(input: TraverseInput): Promise<TraverseResult>;
investigate(options: InvestigateInput): Promise<InvestigateResult>;
context(input: ContextInput): Promise<ContextResult>;
```

```ts
interface RetrieveInput {
  userId: string;
  organizationId: string;   // required
  queryText: string;
  memoryTypes?: string[];
  tags?: string[];
  limit?: number;           // default 20
  graphDepth?: number;      // default 2
  includeCold?: boolean;
  includeArchived?: boolean;
}

interface ContextInput {
  userId: string;
  organizationId: string;   // required
  sessionId: string;        // required
  tokenBudget?: number;
  includeUserModel?: boolean;
  numRecentMessages?: number;
  numRelevantMemories?: number;
  graphDepth?: number;
}
```

There is **no `rerank` field and no `query` field** on `ContextInput`. The HTTP retrieval path does not run a cross-encoder; neural reranking is wired only on the MCP path.

`userId` must equal the actor bound to your key and `organizationId` its organization, or the server returns `403`.

## Response types

```ts
interface RetrieveResponse {
  status: string;
  query: string;
  results: ScoredMemory[];
}

interface ScoredMemory {
  memory: Memory;            // the record is nested under `memory`
  score: number;
  semanticScore: number;
  graphScore: number;
  importanceScore: number;
  recencyScore: number;
  keywordScore: number;
}

interface Explanation {
  memoryId: string;
  source: { sourceType: string; sessionId: string | null };
  classification: { memoryType: string; tags: string[] };
  scoring: ScoreBreakdown;
  supersessionHistory: SupersessionEntry[];
}

interface Memory {
  id: string;
  userId: string;
  organizationId: string;
  memoryType: string;
  title: string;
  content: string;
  confidence: number;
  importance: number;
  utilityScore: number;
  tags: string[];
  memoryState: "active" | "warm" | "cold" | "archived";
  isPinned: boolean;
  isArchived: boolean;
  factKey: string | null;
  validFrom: string | null;
  validTo: string | null;    // null means current
  createdAt: string;
  lastAccessedAt: string | null;
}
```

There is no `scoreBreakdown` object on `ScoredMemory` — the breakdown is flat siblings. `GET /v1/memories/hybrid` still returns the older nested shape, mapped by `hybrid()` into `HybridSearchResponse`.

## `ContextResult`

```ts
class ContextResult {
  userProfile; rules; activeProjects; preferences; goals;
  recentEvents; relevantMemories; tokenUsage; cacheHit; requestId;

  toSystemPrompt(): string;
  toMessages(): Array<{ role: string; content: string }>;
  toMarkdown(): string;
  toDict(): Record<string, unknown>;
}
```

Unlike the Python `Context`, `toSystemPrompt()` here takes **no template argument**.

`cacheHit` is currently always `false` and `requestId` falls back to the literal `"01J"` when no `x-request-id` header was sent. Neither is meaningful.

## Error handling

```ts
import {
  contextaError, AuthenticationError, AuthorizationError, ValidationError,
  NotFoundError, ConflictError, QuotaExceeded, RateLimited, ServerError,
} from "@contexta/client";

try {
  const ctx = await memory.context({ userId, organizationId, sessionId });
} catch (err) {
  if (err instanceof AuthenticationError) {
    console.error("Check your API key");
  } else if (err instanceof RateLimited) {
    console.error(`Retry after ${err.retryAfter}s`);
  }
}
```

`QuotaExceeded` is exported for source compatibility but nothing in v1.5 returns a plan limit.

## Retries, buffering, TLS

Every write carries an `Idempotency-Key`. `429`, `5xx`, and network failures retry with `min(1000 * 2 ** attempt + jitter, 30_000)`, honouring `Retry-After`. When the network is down, writes queue to a durable on-disk buffer.

```ts
const replayed = await memory.flush();  // drain the queue
memory.close();                         // safe to call twice
```

`withContexta()` is the equivalent of Python's `with Contexta(...)`:

```ts
import { withContexta } from "@contexta/client";

const systemPrompt = await withContexta({ apiKey }, async (memory) => {
  const ctx = await memory.context({ userId, organizationId, sessionId });
  return ctx.toSystemPrompt();
});
```

Certificate verification is on by default. To trust the optional self-signed gateway:

```ts
const memory = new Contexta({ apiKey, tls: { caPath: "./certs/cert.pem" } });
// or inline PEM:
const memory = new Contexta({ apiKey, tls: { ca: "<PEM string>" } });
```

Disabling verification is explicit and logs a one-time warning:

```ts
const memory = new Contexta({ apiKey, tls: { rejectUnauthorized: false } });
```

Custom TLS on Node needs a `dispatcher` built from `undici` (an optional peer dependency). Where `undici` is unavailable, or if you already have a TLS-configured `fetch`, pass `fetch` instead and the SDK uses it as-is.

## Runtimes

Node 18+, Vercel Edge Runtime, Cloudflare Workers, Bun, Deno, and modern browsers. **Zero required dependencies** — native `fetch`, `crypto`, and `AbortSignal.timeout`.

## Telemetry

`CONTEXTA_TELEMETRY=false` or `telemetry: false`. It controls a `User-Agent` version header (`contexta-sdk-ts/<version>`) and local counters. Nothing is sent anywhere.
